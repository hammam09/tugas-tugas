# Array Manipulation Exercises

Kumpulan soal latihan manipulasi array dalam JavaScript (10 soal + bonus).

## 📋 Daftar Soal

1. **Antrian Kantin** - Operasi dasar array (push, unshift, shift, pop)
2. **Inventaris Barang** - Menggunakan splice untuk menambah dan menghapus elemen
3. **Mencari Posisi Siswa** - indexOf, includes untuk pencarian data
4. **Potong Data** - Menggunakan slice untuk mengambil bagian array
5. **Data Pegawai Bermasalah** - Manipulasi kompleks dengan splice
6. **Tebak Isi Array** - Prediksi hasil operasi array
7. **Sistem Login** - Validasi user menggunakan includes dan indexOf
8. **Operasi Rahasia** - Kombinasi unshift, splice, dan pop
9. **Manipulasi Bertingkat** - Multiple operations pada satu array
10. **Tantangan Akhir** - Serangkaian operasi kompleks pada array warna

## 🔧 Array Methods yang Dipelajari

- `push()` - Menambah elemen di akhir array
- `pop()` - Menghapus elemen terakhir
- `unshift()` - Menambah elemen di awal array
- `shift()` - Menghapus elemen pertama
- `splice()` - Menambah/menghapus elemen di posisi tertentu
- `slice()` - Mengambil bagian array tanpa mengubah asli
- `indexOf()` - Mencari posisi elemen
- `includes()` - Mengecek keberadaan elemen

## 🚀 Cara Menjalankan

### Menggunakan Node.js:

```bash
node script.js
```

### Menggunakan Browser:

Buka file `index.html` di browser, lalu lihat output di console (F12 atau Ctrl+Shift+I).
