# Dynamic Table Manager

Dashboard manajemen dan rekapitulasi data siswa secara realtime menggunakan HTML, CSS, dan JavaScript.

## 📌 Deskripsi

Dynamic Table Manager adalah aplikasi web sederhana yang digunakan untuk mengelola data siswa secara interaktif. Pengguna dapat menambahkan data siswa, melakukan pencarian berdasarkan kelas, memfilter berdasarkan usia, serta melihat statistik siswa secara otomatis.

Aplikasi ini dirancang dengan tampilan modern, responsif, dan mudah digunakan baik di desktop maupun perangkat mobile.

---

## ✨ Fitur Utama

- ➕ Menambahkan data siswa.
- 👤 Input nama lengkap siswa.
- 🎂 Input umur siswa.
- 🏫 Input kelas atau jurusan.
- 📊 Statistik data siswa secara realtime.
- 👥 Total jumlah siswa.
- 🎂 Rata-rata umur siswa.
- 🏫 Total kelas atau jurusan.
- 🔍 Pencarian berdasarkan kelas/jurusan.
- 🎯 Filter data berdasarkan usia.
- 📱 Responsive design untuk desktop dan mobile.
- 📋 Tabel data siswa yang dinamis.
