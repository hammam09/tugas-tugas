# 📚 Tugas Dasar JavaScript

Repository ini berisi latihan dasar JavaScript yang mencakup konsep-konsep fundamental seperti Variable, Data Type, Statements, Expressions, Operator, dan Program Kalkulator Sederhana.

---

## 🎯 Tujuan Pembelajaran

Melalui tugas ini, saya mempelajari:

- Membuat dan menggunakan variabel
- Mengenal berbagai tipe data JavaScript
- Memahami statement dan expression
- Menggunakan operator dalam JavaScript
- Membuat program kalkulator sederhana
- Menampilkan output menggunakan `console.log()`

---

## 📂 Daftar Materi

### 1. Variable & Data Type

Membuat beberapa variabel untuk menyimpan data:

- Nama lengkap
- Umur
- Tinggi badan
- Status programmer/pelajar
- Hobi favorit

Contoh:

```javascript
let namaLengkap = "Hammam";
let umur = 18;
let tinggiBadan = 170;
let isProgrammer = true;
let hobiFavorit = "Coding";
```

---

### 2. Memahami Sintaks JavaScript

Belajar menulis sintaks JavaScript yang valid dan memahami fungsi setiap baris kode menggunakan komentar.

Contoh:

```javascript
// Membuat variabel nama
let nama = "Hammam";

// Menampilkan nama ke console
console.log(nama);
```

---

### 3. Statements

Mempelajari berbagai jenis statement seperti:

- Deklarasi variabel
- Inisialisasi nilai
- Assignment
- Operasi matematika
- Pemanggilan `console.log()`

Contoh:

```javascript
let umur = 18;
umur = 19;

console.log(umur);
```

---

### 4. Expressions

Mencoba beberapa jenis expression:

#### Arithmetic Expression

```javascript
10 + 5
```

#### String Expression

```javascript
"Hello" + " World"
```

#### Comparison Expression

```javascript
20 > 10
```

#### Logical Expression

```javascript
true && true
```

---

### 5. JavaScript Operator

#### Arithmetic Operator

```javascript
+
-
*
/
%
```

#### Assignment Operator

```javascript
=
+=
-=
```

#### Comparison Operator

```javascript
==
===
!=
>
<
```

#### Logical Operator

```javascript
&&
||
!
```

---

### 6. Program Kalkulator Sederhana

Membuat program sederhana menggunakan dua angka dan melakukan operasi:

- Penjumlahan
- Pengurangan
- Perkalian
- Pembagian
- Modulus

Contoh:

```javascript
let angka1 = 20;
let angka2 = 4;

let penjumlahan = angka1 + angka2;
let pengurangan = angka1 - angka2;
```

---

## ⭐ Bonus: Biodata Digital

Membuat biodata menggunakan variabel dan menggabungkan data menggunakan expression.

Contoh:

```javascript
let nama = "Hammam";
let kotaAsal = "Sidoarjo";

let perkenalan = "Halo, nama saya " + nama;
```

Output:

```text
=== BIODATA DIGITAL ===

Nama: Hammam
Umur: 18
Kota Asal: Sidoarjo
Hobi: Coding
Bahasa Pemrograman Favorit: JavaScript
```
