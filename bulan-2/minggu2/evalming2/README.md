# Evaluasi Minggu 2 - JavaScript Basic

Repositori ini berisi kumpulan latihan dasar JavaScript. Latihan ini mencakup materi mengenai sintaks, statements, comments, variables, tipe data, operator, control flow, dan looping.

## Daftar Latihan

File `script.js` memuat 20 latihan penyelesaian masalah menggunakan JavaScript, di antaranya:
1. Pengecekan Tipe Data
2. Penggabungan String dan Angka (Concatenation)
3. Operasi Aritmatika Dasar
4. Operator Penugasan (Assignment Operators)
5. Menentukan Bilangan Genap/Ganjil dan Positif/Negatif
6. Sistem Penilaian Huruf Berdasarkan Angka (A, B, C, D, E)
7. Menentukan Angka Terbesar dari 3 Variabel
8. Penggunaan Operator Logika (AND, OR)
9. Menentukan Tahun Kabisat
10. Program FizzBuzz
11. Operator Increment (`++`)
12. Menghitung Total Bilangan Ganjil (1-100)
13. Membuat Pola Segitiga Bintang Menggunakan Looping bersarang
14. Menghitung Jumlah Nilai Elemen Array yang Lebih dari 10
15. Mencari Bilangan Prima (1-100)
16. Logika Control Flow Bersarang (Nested If)
17. Simulasi Login Sederhana dengan `prompt` dan `alert`
18. Menentukan Jumlah Hari Berdasarkan Bulan Menggunakan Switch-Case
19. Membuat Deret Angka Biner (1, 2, 4, 8, ...)
20. Akumulasi Total Nilai dengan Kondisi Ganjil/Genap

## Cara Menjalankan Program

Karena program ini berjalan di sisi klien (browser) dan kebanyakan menggunakan fungsi `console.log()` untuk mencetak hasil, Anda dapat menjalankannya dengan cara berikut:

1. Buka file `index.html` menggunakan web browser (seperti Google Chrome, Mozilla Firefox, dll).
2. Anda akan melihat sebuah dialog `prompt` untuk memasukkan username dan password (bagian dari Latihan 17). Anda bisa mengisinya (username: `admin`, password: `123`) atau melewatinya.
3. Buka **Developer Tools** di browser Anda (tekan `F12` atau klik kanan pada halaman lalu pilih **Inspect** / **Inspeksi**).
4. Masuk ke tab **Console** untuk melihat hasil keluaran dari setiap baris kode yang dieksekusi.
